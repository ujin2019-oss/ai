## 촬영·생성 가이드
- 상품 컷 4장은 **같은 각도·같은 배경·같은 조명**으로 통일해야 카드가 정돈되어 보입니다.
- 배경색은 `--color-bg-alt` (`#EFE8D6`)와 맞추면 카드와 자연스럽게 이어집니다.
- 히어로/배너 이미지는 텍스트가 얹히는 쪽(왼쪽)에 복잡한 디테일이 없도록 비워 주세요.
- 웹용으로 저장 시 `.webp` 사용을 권장합니다 (사용 시 HTML의 `src` 확장자도 함께 변경).
